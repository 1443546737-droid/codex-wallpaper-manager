首个公开测试版，只包含壁纸功能。

本机视频、图片和项目预览图；浮动管理器；缩略图缓存；G / PG-13 / R-18 与未标注筛选；逐壁纸取景；视频自身音轨控制；透明聊天、输入框与文件预览面板。

需要 Windows、Node.js 22+、Codex 桌面版和已下载的本地 Wallpaper Engine 项目。运行时不需要 Steam 或 Wallpaper Engine 常驻；需通过 Codex Wallpaper 入口启动本机连接和后台服务。首次安装后需要完全退出 Codex 再打开一次。

Scene/Web 使用预览图，完整场景暂不支持。较大视频可能缓存转码。Codex 界面更新可能影响兼容性。

下载 ZIP 解压后，可让 Codex 阅读 README.md 和 INSTALL_FOR_CODEX.md 完成安装，也可直接运行 scripts/install.ps1。卸载方式见 README。

本地验证覆盖界面、元数据、缩略图、取景、保存恢复、独立安装与卸载。GitHub Actions 的结果以仓库页面为准。
